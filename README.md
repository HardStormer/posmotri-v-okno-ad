# Посмотри в окно

Проектная работа Яндекс Практикума: стилизация готового приложения с видео из окон разных городов.

Репозиторий: https://github.com/HardStormer/posmotri-v-okno-ad

## Технологии

- раскладка на Flexbox;
- кастомные чекбоксы на псевдоэлементах;
- состояния `:hover`, `:active`, `:focus-visible` и `:has()`;
- `object-fit`, `text-overflow` и `line-clamp` для контента.
